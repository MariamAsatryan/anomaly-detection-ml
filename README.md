This is Anomaly Detection project in numerical data using Machine Learning Algorithms: K-NN, LOF, Isolation Forest, Random Forest. The datasets were constructed from EDA Laboratory, available at https://labs.ece.ncsu.edu/eda. Each dataset represents each standard cell's timing or power values from .lib file's matrices. Using numerical datasets with different feature space dimensionalities anomaly detection was done by models mentioned earlier. For each model's accuracy calculations ROC AUC method was used.
